OCR Claim Forms – CMS-1500 (HCFA-1500)

This work focuses on extracting key information from CMS-1500 (HCFA-1500) healthcare claim forms using Optical Character Recognition (OCR) and Natural Language Processing (NLP).

The system takes a clear, typed CMS-1500 claim form image (PNG format) as input. OCR is used to convert the image into text, and an NLP-based extraction process is applied to identify and extract relevant fields from the OCR output.

Information extracted from the CMS-1500 (HCFA-1500-1) form includes:

Patient name

Patient date of birth

Patient gender

Patient address

Insured name

Insurance provider name

Policy or insured ID number

ICD-10 diagnosis codes

CPT/HCPCS procedure codes

Date of service

Charge amounts

Total billed amount

This serves as a basic proof of concept demonstrating how OCR and NLP techniques can be applied to structured healthcare claim forms to convert unstructured claim form images into structured digital data.

For best results, the CMS-1500 claim form images should be high quality, properly aligned, and contain clearly typed text.
